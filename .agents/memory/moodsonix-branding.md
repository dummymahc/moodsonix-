---
name: Moodsonix branding
description: Branding boundary for user-visible naming versus technical identifiers.
---

Use “Moodsonix” for user-facing app labels, About/welcome content, updater copy, documentation, and runtime presence text.

**Why:** The project was rebranded from Echo Music, but its Android package names, resource keys, deep-link schemes, and existing service URLs are compatibility-sensitive.

**How to apply:** Update displayed values and labels, but do not rename package paths, resource keys, URI schemes, widget action identifiers, or external service hosts unless a migration is explicitly requested.
